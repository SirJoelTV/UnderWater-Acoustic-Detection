Project Abstract

Detection and classification of underwater objects from acoustic data presents a significant challenge due to the complex nature of the underwater environment. This project proposes an AI-driven solution for robust detection and classification of objects within underwater acoustic data — developing an anomaly detection module against ambient noise, precisely extracting temporal durations, computing salient acoustic features, and implementing a classification system for predefined object classes. This approach enhances accuracy and efficiency for applications in marine conservation, underwater exploration, and naval security.

CNN Deep Learning

Convolutional Neural Networks extract hierarchical spatial-temporal features from spectrograms and raw acoustic signals, enabling robust pattern recognition even in high-noise environments.

  • Noise-robust signal processing
  • Transfer learning support

Anomaly Detection

Statistical and learned models identify anomalous acoustic signatures against dynamic ambient noise baselines.

Feature Extraction

Log-mel spectrogram, spectral centroid, zero-crossing rate, and CNN-learned embeddings capture distinct object signatures.

Multi-Class Output

Objects classified into distinct categories — submarines, vessels, marine life, and other acoustic targets.

Temporal Analysis

Millisecond-accurate extraction of anomaly onset and duration provides precise event timelines.
