Abstract

Detection and classification of underwater objects from acoustic data presents a significant challenge due to the complex nature of the underwater environment. This project proposes an AI-driven solution for robust detection and classification — developing an anomaly detection module against ambient noise, extracting temporal durations, computing salient acoustic features, and implementing a multi-class CNN classifier for predefined object categories. Advancing the frontiers of marine conservation, underwater exploration, and naval security.

System Architecture

Four-Stage Processing Pipeline

From raw acoustic signal to classified detection — every stage purpose-built for underwater acoustics.

Signal Ingestion

Raw .wav files are loaded, resampled to target rate, normalized, and segmented into overlapping windows for analysis.

WAV Input Resampling Normalization

Anomaly Detection

An autoencoder trained on ambient ocean noise flags segments with high reconstruction error — any departure from background is an anomaly.

Autoencoder Log-Mel Features IQR Threshold

Duration Extraction

Anomalous regions are merged and precisely timestamped. Overlapping windows are deduplicated to yield clean onset/offset boundaries.

Timestamps Deduplication Segmentation

CNN Classification

Anomalous audio is converted to a mel spectrogram and fed into a SimpleCNN, producing class probabilities across all target categories.

Mel Spectrogram SimpleCNN Multi-Class
Capabilities

Built for the
Ocean Floor

Every component designed to handle the unique challenges of underwater acoustic environments.

Ambient-Aware Anomaly Detection

Autoencoder trained exclusively on the quietest 10% of ocean recordings — any sound with activity registers as anomalous.

Log-Mel Acoustic Features

64-band mel spectrograms capture the frequency-time structure that distinguishes ships, marine life, and natural sounds.

Confidence Thresholding

Predictions below 60% confidence are automatically flagged as "Unknown" — never reporting a false certainty.

LangChain Pipeline

Autoencoder and CNN are chained via LangChain's RunnableLambda — clean, modular, and easy to extend.
